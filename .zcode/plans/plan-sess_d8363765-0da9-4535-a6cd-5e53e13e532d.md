## A. 產出路徑重組

```
tools/design/{項目}/lvgl/           ← 該 design 的 LVGL 輸出（跟 design 走,含離線資源）
├── ui/                            ← 板上會上傳到 /ui 的框架代碼
│   ├── app.py  registry.py  launcher.py  board.py  ui_common.py
│   └── page/{overview,monitor,control,settings}.py
└── src/                           ← 板上會上傳到 /ui/src 的資源
    ├── icons_16.bin + lv_icons.py
    ├── zh_hant_16.bin
    └── lv_ui_fx.py  fx_notes.md
```

- `designlib.py` 加 `lvgl_path(design_name)` / `lvgl_src_path()`，design.json 記每 design 產出狀態
- generators（uiframe/icons/zhfont/fxgen）接受 design 參數,輸出到該 design 的 lvgl/
- server：`/api/generate` 加 `design` 參數；`/api/designs` 回傳各 design 的 lvgl 產出狀態
- 舊 `workspace/out/` 保留不刪

## B. 模擬器四區拆分（融入工具頁）

「設計預覽 / 模擬器」分頁：

```
┌─ 工具列:Design | 頁面按鈕 | 縮放 ─────────────┐
├─ HTML 設計稿預覽 iframe（上） ───────────────┤
├─ Display canvas（下:模擬器跑該 design 代碼）──┤
├─ 代碼區 textarea ───┬─ REPL 輸出 ──────────┤
└─ [跑 / 儲存 / 重新生成] ─────────────────────┘
```

沿用 sim 的 iframe+data-cscript 機制（探索已確認）：
- `iframe#emscripten-iframe`（id 必須同名,runtime 讀 `window.parent` 拿它）src=`/sim/lvgl.html`（本地）
- Display：工具頁 `<canvas id="canvas">`（lvgl.html 抓父頁面 #canvas 當 render target）
- 代碼區：textarea（輕量,可編輯）;「跑」→ 本地 LZString 壓縮 → 設 `data-cscript` → 重載 iframe
- REPL：工具頁監聽 `micropython-print` 事件寫入 div;輸入送 `iframe.contentWindow.process_char()`
- 頂欄按鈕：跑 / 儲存（存回 design/lvgl/ui/）/ 重新生成
- 切 design 時代碼區自動載入該 design 的 lvgl/ui 代碼

## 實作步驟

1. `designlib.py`：lvgl_path/lvgl_src_path + 產出狀態
2. generators 改目標（design 參數,預設沿用）
3. server：generate 加 design、designs 回傳 lvgl 狀態、前端引用本地 lz-string
4. 前端：模擬器拆分頁（iframe+canvas+textarea+REPL+跑/儲存）
5. 測試：離線斷網跑一次 → 切 design → 代碼載入 → 跑 → display 顯示 → REPL 輸出

## 風險與因應

- lvgl.html 抓父頁面 `#canvas`、`#emscripten-iframe` id 硬編碼 → 工具頁用同名 id
- LZString 前端載入本地檔（不連 CDN）
- 全程斷網實測驗證零外部請求
